### 1.2 Architectural Posture
- **Static Analysis & Test Baseline:** `flutter analyze --no-pub` passes with **0 issues**. Existing test suites are substantial (`1,961` passing core/service/security/architecture tests + `766` modes/UX tests + `221` player presentation tests), and `lib/l10n/app_{en,ar,es}.arb` maintain parity at `3,679` keys each with 0 empty values. However, `empty_catch_ratchet_test.dart:15` pins a technical-debt baseline of **364 empty catches**, and critical native/network/sync/recovery paths lack automated regression tests.
- **Strengths:**
  - Lock-free 64-slot hazard-reclaimed `DspParamSnapshot` publishing in `AudioDspEngine`, preallocated `LookaheadLimiter`, 4-slot lock-free `HrtfBinaural`, fuel-limited `LiveProg` VM, and `ReentrantReadWriteLock` + `Cleaner` native lifetime management in vendored `just_audio`.
  - Clean reactive patterns via `PulsrCubit`, serialized queue mutations via `_queueMutex` (where used), transactional `applyProfile` scaffolding, and responsive shell/tablet layouts.
- **Systemic Weaknesses:**
  1. **Lifecycle & Concurrency Gaps:** Non-resettable DI bootstrap `Completer`, screen-scoped singletons (`DlnaRendererService`, `RemotePlaybackRuntime`), popped-context sheet actions, un-tokened cancel/retry races in downloads, and missing generation/mount guards across async cubits and widgets.
  2. **Pure-Build & Offline Policy Leaks:** Multiple services (`ScrobblerService`, `StreamUrlVerifier`, `DiscordRpcService`, `AppUpdateService`, `CanvasRepository`, `FileIntentHandler`, `AuthService`, metadata fetchers) bypass `AppConfig.isPure` or offline checks.
  3. **Security & Privacy Gaps:** Exported `NowPlayingWidget` receiver self-permission bypass, `server/pulsr_party` `X-Forwarded-For` spoofable rate-limit DoS, `AppUpdateService` redirect bypass + optional SHA-256, `ErrorLogger` unredacted Sentry payloads, and `DiagnosticsBundleService` exporting raw user `liveProgCode`.
  4. **Native RT-Safety & Bridge Mismatches:** `nativeIsUsbExclusive` JNI ABI arity mismatch, `UsbExclusivePlugin.writeDsd` `ClassCastException`, unwired `PcmToDsd` defeating bypass, RT-thread heap allocations (`PendingUsbRetry`) and logging (`AAudioSink`, `UsbAudioSink`), and missing Direct USB discontinuity clock rebasing.

### 1.3 Critical Risk Summary (14 Verified Critical Findings)
1. **Data Loss:** `CloudSyncService` `InsertMode.insertOrReplace` triggers `ON DELETE CASCADE` wiping playlist memberships (`CRIT-02`); unpersisted `_lastSyncedUid` + incomplete `resetSessionState()` leaks cross-account sync state (`CRIT-03`).
2. **Data Integrity & Undo Corruption:** `TagEditorCubit` omits `_pushHistory` on artwork/auto-fetch (`CRIT-09`), spams error SnackBars on every keystroke (`CRIT-10`), and clears `_batch*Edited` flags on failed saves (`CRIT-11`).
3. **Reliability & Crashes:** Bootstrap DI retry never re-invokes `configureDependencies` (`CRIT-01`); `YtDownloadForegroundController.release()` emits false `progress: 100` (`CRIT-05`); download cancel/retry/delete races corrupt active task tracking and artwork (`CRIT-06`, `CRIT-12`); `AuthSheet` `BlocConsumer` pops parent routes on every sync emit (`CRIT-13`).
4. **Security & DoS:** `server/pulsr_party` leftmost `X-Forwarded-For` trust enables rate-limiter bypass and global `maxKeys` DoS (`CRIT-14`).
5. **Broken Core Features:** `YtmAccountService.validateSessionDetailed` accepts guest `FEmusic_home` and skips OAuth 401 refresh (`CRIT-04`); `ScrobblerService` broadcasts Android scrobble intents during Quran playback & breaks Libre.fm (`CRIT-07`); Home "Decades" buttons route to dead `/year` screen (`CRIT-08`); `DlnaScreen` disposes `DlnaRendererService` on back navigation killing cast (`CRIT-15` -> tracked with Criticals); `ListenTogetherService.init()` is never called at startup (`CRIT-16`). *(15 distinct Critical entries cataloged in Section 3.)*
