Yes. The default Pulsr Pure build removes the Android INTERNET permission at the manifest level and ships without Firebase, Sentry, cloud sync, or YouTube code. Network features exist only in the optional Plus build and stay off by default.
Bit-perfect requires the exact lossless source bitstream to reach your DAC. Lossy codecs (MP3, AAC, Opus, Vorbis) have already discarded audio data, and Bluetooth re-encodes audio. Pulsr enforces honesty by blocking lossy/Bluetooth claims and verifying lossless custody with SHA-256 hashes.
Pulsr bundles 652 five-band headphone compensation curves derived from published measurements. It matches connected headphones by name, applies automatic preamp headroom to avoid clipping, and lets you stack headphone EQ with room correction.
Each client exchanges timestamps with the self-hostable Go party server over WebSockets, keeping the minimum-RTT offset from a 12-sample window with a monotonic server clock and a 10-second ping loop.
